An agentic AI property search that shows what it understood

Scout is a conversational way to find a home to rent in Dubai, explored for Property Finder. You say what you want in your own words. Scout keeps a short memory of what it understood, marks what it guessed, and shows only the homes that match. It runs on a real model. Nothing is mocked.

The challenge

In a filter panel, your intent is on screen. In a chat, it scrolls away.

Search with filters is easy to read. What you asked for sits in one place, you set every part of it, and the results are clearly built from it.

A chat loses that. What you want is spread across messages: some said, some implied, some changed three messages later. And you can’t see what the results are based on.

The design

One loop, and a memory you can see.

  1. 1IntentYou say what you want, in your own words, however incomplete.
  2. 2UnderstandingScout forms a few preferences. Each one says where it came from.
  3. 3ResultsHomes that match that understanding, and only that.
  4. 4RefineTalk, or tap the memory. Scout says what changed.

Two rules hold it together

Nothing changes silently.

What you see in the memory is exactly what the results were built from.

01

See it. Always in view, never in a panel.

Filters do one thing well: they’re always there. I kept that and dropped the panel. One line above the keyboard, in thumb reach, written in words instead of controls.

No quick-reply chips either. Chips are filters by another name.

02

It infers, and shows its working.

An agent that only does what it’s told is a form. Scout reads between the lines: a dog means a pet-friendly building, kids mean schools nearby probably matter.

What must be true filters. What’s only likely ranks. Every guess is marked as one.

05

No results is never the answer.

Saying “no results” is easy. A smart agent works out why, and what would change it.

Scout first widens to what you’d likely accept anyway: the neighbouring areas. If still nothing fits, code tests every requirement, finds the one blocking the most homes, and Scout names it with what you’d get. It never drops a requirement without asking. You decide what to give up.

How the agent works

The model reads people. Code does the counting.

Understanding a person is fuzzy work. Matching homes is exact: a budget is a number, and a building either allows pets or it doesn’t. So each half goes to what does it best. The memory on screen is where they meet.

Model: meaning and languageCode: rules and counting
1 · ModelUnderstandTurns your message into preferences, and where each came from.Claude Haiku 4.5, returns JSON
2 · CodeMatchApplies them to the listings. Results can never be looser than the memory shows.Plain code
3 · CodeFind the way outIf nothing fits, tries dropping each requirement and keeps the one that frees the most homes.Plain code
4 · ModelReplySays what changed and what’s on screen. No recap.Claude Sonnet 5, streamed

The memory on screen is the single source of truth. Results are built from it and nothing else, and every change to it is said out loud once.

Technical choices for this prototype

2Models, each chosen for its job: a fast one to understand, a stronger one to write.
46Seeded homes across 20 Dubai communities, shaped to test the edges of the conversation.
~6sSaved on every turn by asking for plain JSON first, with strict schema mode as the fallback.

Building it

Built with Claude Code, end to end, in a few hours.

I decided what Scout should do, how it should talk, and where the model stops and code takes over. Claude Code wrote the interface, the prompts, the matching code and the tests. I judged every answer.

The prompts are design work. Scout’s voice lives in the reply prompt: short sentences, plain international English for a city of expats, no idioms, always the area, the price and the distance.

The test it has to pass

A script replays a seven-turn conversation against the live model. It fails if Scout…

  • uses an em dash
  • uses an idiom or filler, like “good news”
  • asks a question while homes are on screen
  • opens two replies the same way
  • forgets a preference you never took back
  • shows a home over a firm budget
  • shows a no-pets home after you mention a cat or dog
  • reads “10k a month” as anything but 120k a year
